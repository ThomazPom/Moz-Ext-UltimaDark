Extension settings

Toggle current site shortcut
Change the shortcut here if it conflicts with another application or extension. Use Firefox shortcut syntax, such as Alt+Shift+U. Pressing it repeatedly alternates the current site between excluded and included.
Shortcut behavior
Ask first is the default and shows the exact patterns before applying them; press Enter to confirm. Apply instantly changes the site immediately without opening a confirmation.
Keyboard shortcuts are not supported on this Firefox platform.
Image processing
Darkens interface images while trying to preserve photos and artwork. Some images may be classified incorrectly.
Allow website service workers
Enabled leaves website service workers available. Disable only if UltimaDark fails on a service-worker-based site: the legacy workaround unregisters and hides service workers where UltimaDark runs. This may disrupt offline features, notifications, or background updates. Reload affected tabs after changing it.
Keep image processors ready
Keeps a set of image processors ready between images, avoiding repeated startup work for faster processing. Disable it to start a fresh processor for each image, which may help with compatibility problems.
Image detection method
